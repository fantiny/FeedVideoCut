# tag_cut 视频拆解打标 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 在 `tag_cut/` 交付 Electron 审核台 + Python 多层拆解打标流水线，对 `input/` 视频全自动切镜打标并支持人工改标导出；云端 VLM 可配，默认关闭。

**Architecture:** Electron 桌面壳通过 HTTP 调用本机 FastAPI；流水线按 L0→切镜→L1→L2→L3–L6 分层，能力经 Provider 注入；结果落 `tag_cut/data/`，原片只读。

**Tech Stack:** Python 3.11+, FastAPI, uvicorn, FFmpeg/ffprobe, PySceneDetect, ultralytics/YOLOv8 (optional weights), Electron + React + Vite, pytest, PyYAML

**Design doc:** `docs/plans/2026-09-03-tag-cut-design.md`
